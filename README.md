# TOKYO GANG

الموقع الرسمي ولوحة الإدارة المركزية لـ TOKYO GANG. المشروع مبني باستخدام Next.js ويعمل على Cloudflare Workers عبر OpenNext.

## التشغيل محلياً

```bash
npm install
npm run dev
```

## إعدادات لوحة الإدارة

هذه إعدادات عادية وليست أسراراً، والقيم الفعلية موجودة في `wrangler.jsonc`:

| المتغير | وظيفته | القيمة الحالية |
| --- | --- | --- |
| `TOKYO_ADMIN_PAGE_SIZE` | عدد التقديمات في كل صفحة | `24` |
| `TOKYO_REPORT_DAYS` | مدة التقرير الإداري | `7` أيام |
| `TOKYO_SYNC_SECONDS` | الفاصل بين مزامنة أعضاء Discord | `60` ثانية |

كل إعدادات Discord الاحتياطية مجمعة داخل Secret واحد اسمه `TOKYO_DISCORD_CONFIG`.

الإعداد اليومي لا يحتاج تعديل Secrets:

- من لوحة الإدارة افتح **النظام** أو **الأعضاء**، ثم الصق ID الرتبة المطلوبة مرة واحدة. تحفظ الرتب في قاعدة البيانات وتبقى قابلة للتعديل عند تغيير رتب السيرفر.
- من قسم **مركز Webhooks** اختر قناة التقديمات وقناة سجل الإدارة. ينشئ الموقع Webhooks جديدة ويحفظها في قاعدة البيانات، ويعيد إنشاء الـWebhook تلقائياً إذا تعطل.
- رتبة `TOKYO GANG` هي التي تحدد أعضاء العصابة الذين تتم مزامنتهم إلى قاعدة البيانات. بعد حفظها تبدأ المزامنة مباشرة، مع حماية تمنع تعطيل كل الأعضاء إذا رجع Discord بنتيجة فارغة مؤقتاً.

مفاتيح Discord وقاعدة البيانات تبقى Cloudflare Secrets ولا يجب إضافتها إلى Git.
